# Волна — плеер без рекламы (Android)

Музыкальный плеер в стиле YouTube Music: поиск, медиатека, плейлисты, офлайн-режим, фоновое воспроизведение с управлением из шторки уведомлений и **перенос плейлистов и альбомов по ссылке**.

> Статус: версия 0.1. Код **ни разу не собирался и не запускался на устройстве** (в среде разработки нет доступа к серверам Flutter/Android). Парсеры чужих сервисов написаны по известным форматам и не проверялись на живых серверах. Если сборка упадёт или импорт не сработает, пришлите текст ошибки — это поправимо.

## Откуда берётся музыка

Приложение не обходит рекламу и подписки других сервисов: оно не умеет брать аудио из YouTube Music, Яндекс Музыки или VK. Источники:

1. **Ваши файлы** — mp3/flac и др. с телефона («Медиатека» → значок «Добавить файлы»). Название и исполнитель читаются из тегов файла (ID3, FLAC), а если тегов нет — из имени файла.
2. **Каталог Jamendo** — легальная музыка независимых исполнителей (Creative Commons), без рекламы. Нужен бесплатный ключ `client_id` (devportal.jamendo.com → создать приложение), вводится в «Настройках».

Популярных хитов в Jamendo обычно нет, поэтому лучше всего работает связка: **свои файлы + перенос плейлиста** — приложение само найдёт совпадения среди ваших файлов.

## Перенос плейлиста по ссылке

Вкладка **«Импорт»**: скопируйте ссылку (в других приложениях — «Поделиться» → «Копировать ссылку»), откройте вкладку — приложение предложит перенести ссылку из буфера обмена. Читаются только **названия и исполнители**; затем каждый трек ищется сначала в вашей медиатеке, потом в Jamendo. Что не нашлось — не переносится (список ненайденных можно скопировать). Сопоставление понимает опечатки, «feat.», «(Remastered)», кириллицу/латиницу («Кино» ≈ «Kino»), а версии «live», «remix», «acoustic» отличает от оригинала.

| Сервис | Как |
|---|---|
| Яндекс Музыка | ссылка на альбом или плейлист (плейлист должен быть открыт по ссылке) |
| YouTube / YouTube Music | ссылка на плейлист или альбом (в ссылке есть `list=…`), длинные плейлисты подгружаются целиком |
| Spotify | ссылка на альбом или плейлист (до 100 треков) |
| VK Музыка | пробуется чтение страницы, но VK обычно отдаёт список только после входа в аккаунт — тогда вставьте список текстом |
| Любой сервис | вставьте список текстом: `Исполнитель - Название`, по одной песне на строке |

Сервисы не дают официального открытого доступа, поэтому чтение может перестать работать, если сервис поменяет формат. YouTube и Spotify в России могут открываться только через VPN (нужен лишь на момент переноса списка).

## Как получить APK без установки программ на компьютер

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (Private подойдёт).
2. Загрузите в него **всё содержимое этой папки** (Add file → Upload files). Папка `.github` скрытая — если она не загрузилась, создайте файл вручную: Add file → Create new file, имя `.github/workflows/build-apk.yml`, вставьте содержимое из файла `ci/build-apk.yml`.
3. Откройте вкладку **Actions** → «Сборка Android APK» → **Run workflow**.
4. Через 5–10 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `volna-apk`, распакуйте. В `reports` лежат отчёты проверки кода и тестов.
5. Скопируйте `app-release.apk` на телефон и установите (разрешите установку из неизвестных источников).
6. В приложении: Настройки → вставьте ключ Jamendo (по желанию).

Если шаг «Собрать APK» красный — откройте его, скопируйте последние строки с ошибкой и пришлите.

## Сборка на своём компьютере

Нужны Flutter SDK и Android Studio (Android SDK).

```
flutter create --org com.volna --project-name volna --platforms=android .
dart run tool/patch_android.dart
flutter pub get
flutter build apk --release
```
APK появится в `build/app/outputs/flutter-apk/app-release.apk`.

## Что умеет

- Поиск (по медиатеке и каталогу), главная с популярным за неделю
- Фоновое воспроизведение, плеер в шторке, перемотка, перемешивание, повтор
- Медиатека, плейлисты, добавление файлов с телефона (с чтением тегов)
- Скачивание треков для прослушивания без интернета (по одному или целым плейлистом)
- Перенос плейлистов (см. выше)

## Структура

```
lib/main.dart             запуск, тема
lib/app_state.dart        медиатека, плейлисты, загрузки, плеер
lib/models.dart           Track, UserPlaylist
lib/core/text_norm.dart   сравнение названий (транслитерация, версии, опечатки)
lib/core/id3.dart         чтение тегов mp3/flac
lib/core/encoding.dart    windows-1251, HTML-сущности
lib/sources/jamendo.dart  каталог Jamendo
lib/import/               чтение ссылок и сопоставление треков
lib/ui/                   экраны
tool/patch_android.dart   настройка Android для фонового плеера и иконки
test/                     автотесты
```
